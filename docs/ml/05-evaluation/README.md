# 보정과 독립 평가

상태: 실행 전 계획 · 2026-09-26. 실제 수행 결과는 같은 디렉터리의 결과 문서로 갱신한다.

## S — 상황

정답 없는 데이터에서 표시 비율을 오탐률이라 부르면 검증 범위를 과장한다. 모델 점수는 공격 확률이 아니다.

## T — 과제와 이유

calibration으로 threshold를 정하고 별도 test에 고정 적용하며 모델별 비용과 한계를 기록한다.

## A — 실행 방법과 선택 이유

비교 연산은 score > threshold로 고정하고 ties를 시험한다. HTTP는 flag 비율만 보고한다. 라벨 자료는 confusion matrix·precision·recall·FPR와 분모를 기록한다. test로 파라미터를 조정하지 않는다.

## 예상 문제와 개선 계획

양성이 없거나 test가 작으면 해당 지표를 null/미확인으로 표시한다. 단일 run·부분 데이터 결과를 운영 탐지 성능으로 일반화하지 않는다.

## R — 결과

미실행. 계획을 통과 결과로 표시하지 않는다. 실행 명령·환경·입력 범위·소요 시간·검사 결과·실제로 발생한 문제와 수정 내용을 기록한다.
