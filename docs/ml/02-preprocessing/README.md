# 자료별 전처리

다음 S/T/A는 2026-09-26 실행 전에 기록한 계획이다. 이후 수행 여부와 실제 문제·개선·검증은 [결과 기록](RESULTS.md)을 따른다.

## S — 상황

잘못된 시각·중복·누락을 그대로 넣으면 이상 행동과 수집 오류가 섞인다. 공개 가명 IP는 인증 사용자 신원이 아니다.

## T — 과제와 이유

원자료별 엄격한 parser와 오류 집계, 중복 정책, 원본 Git 제외를 구현한다.

## A — 실행 방법과 선택 이유

HTTP Combined Log와 EClog ticks를 별도 adapter로 처리한다. URL query를 입력/결과에 보존하지 않고 경로 집계만 한다. 알 수 없는 bytes는 0으로 만들지 않는다. RBA·RBD는 schema audit 후 adapter를 작성한다.

## 예상 문제와 개선 계획

행 순서·시각·결측·잘린 파일 fixture를 검증한다. 원문 인증정보·원자료 행은 보고서에 출력하지 않는다.

## R — 결과

계획 작성 당시 미실행이었다. 이후 실제 실행과 미완료 범위를 [RESULTS](RESULTS.md)에 기록한다.
